# Microsoft Excel Online: қосу және телефоннан пайдалану

Сайт тапсырысты алдымен қорғалған PostgreSQL дерекқорына сақтайды. Excel Online — тапсырыстарды телефоннан қарап, өңдеуге арналған қосымша құрал. Excel байланысы үзілсе де, сайт тапсырыстарды дерекқорға қабылдай береді.

## Microsoft аккаунтынсыз жұмыс істеу

Тапсырыстарды сайттың әкімші кабинетінде тікелей басқаруға болады. Кестемен жұмыс істеу үшін сыртқы аккаунтсыз қолмен экспорт/импорт та бар:

1. `/admin` бетіне сайттың әкімші құпиясөзімен кіріп, **«.xlsx жүктеу»** түймесін басыңыз.
2. Файлды құрылғыда `.xlsx` өңдей алатын қолданбамен ашыңыз. Қолданбаның өзі аккаунт талап етсе, аккаунтсыз жұмыс істейтін жергілікті қолданбаны қолданыңыз немесе сайт кабинетінде тікелей өңдеңіз.
3. Тек **Күйі**, **Әкімші ескертпесі**, **Жеткізу құны (₸)** және **Трек-нөмір** бағандарын өзгертіңіз. Құрылымды, клиент деректерін, жасырын ID мен уақытты сақтаңыз; формула, жаңа тапсырыс немесе жаңа парақ қоспаңыз.
4. Өзгерісті `.xlsx` пішімінде сақтаңыз. Кабинетте сол файлды таңдап, **«Өзгерістерді импорттау»** түймесін басыңыз. Файл шегі — 4 МБ. Сайт өзгерген тапсырыстар санын көрсетеді.
5. Файл жүктелгеннен кейін өңделетін тапсырыс сайтта жаңартылса, бүкіл импорт тоқтайды. Жаңа `.xlsx` жүктеп, қажетті өзгерістерді соған көшіріңіз. Ешбір жол үнсіз үстінен жазылмайды.
6. Сәтті импорттан кейін келесі өңдеуге жаңа көшірме жүктеңіз. Файлда жоқ жолдар сайттан жойылмайды; импорт жаңа тапсырыс жасамайды.

Бұл әдіске Microsoft тіркелгісі, OneDrive, app registration немесе client secret қажет емес. Өзгерістер файлды өзіңіз импорттағанда ғана сақталады. Төмендегі Microsoft баптауы — қосымша Excel Online мүмкіндігіне арналған.

## Бір рет баптау (техникалық маман)

1. Microsoft Entra басқару орталығында **App registrations → New registration** арқылы веб-қолданба тіркеңіз. **Supported account types** өрісінде **Accounts in any organizational directory (Any Microsoft Entra ID tenant — Multitenant)** таңдаңыз. Осы баптау әкімшіге кейін басқа ұйымның Microsoft 365 жұмыс/оқу тіркелгісін қосуға мүмкіндік береді. Бұрын single-tenant қолданба жасалған болса, оның қолдайтын тіркелгі түрін осы multitenant нұсқасына ауыстырыңыз.
2. **Authentication → Add a platform → Web** бөлімінде нақты жарияланған доменге арналған қайту мекенжайын көрсетіңіз. Үлгі:
   `https://muza-decors.vercel.app/api/admin/excel/callback`.
   Бұл тек үлгі: Vercel берген нақты домен басқа болса, оны ауыстырыңыз.
3. **API permissions → Microsoft Graph → Delegated permissions** ішінде `Files.ReadWrite` және `offline_access` рұқсаттарын қосыңыз. Ұйым саясаты талап етсе, Microsoft 365 әкімшісі келісім береді.
4. **Certificates & secrets** бөлімінде client secret жасаңыз. Оның **Value** мәнін көшіріңіз; Secret ID мәні жарамайды. Мерзімі аяқталмай тұрып жаңартыңыз.
5. Vercel жобасының **Settings → Environment Variables** бөліміне серверлік мәндерді енгізіңіз:

| Атауы | Мәні |
|---|---|
| `MICROSOFT_CLIENT_ID` | Application (client) ID |
| `MICROSOFT_CLIENT_SECRET` | Client secret Value |
| `MICROSOFT_TENANT_ID` | `organizations` — әртүрлі Microsoft 365 ұйымдарының тіркелгілеріне арналған; бір ұйымның Tenant ID мәнін қоймаңыз |
| `SITE_URL` | Нақты сайттың толық HTTPS мекенжайы, соңында `/` қажет емес |
| `SESSION_SECRET` | Кемінде 32 таңбалы кездейсоқ құпия мән |
| `DATABASE_URL` | Сайттың PostgreSQL қосылымы |

6. Дерекқор көшіруін орындап, жаңа deployment жасаңыз. Microsoft кестесі `initializeExcelDatabase()` арқылы жасалады; жобаның migration сценарийі оны шақыруы керек.
7. `/admin` бетіне кіріңіз. **Excel Online қосу** түймесін басыңыз. OneDrive қызметі белсенді Microsoft 365 жұмыс/оқу тіркелгісімен кіріп, рұқсат беріңіз.
8. Жүйе сол тіркелгінің OneDrive қоймасында жеке `Muza-orders-….xlsx` файлын жасайды. Ол жалпыға жарияланбайды. Әкімші бетінде **Excel Online ашу** сілтемесі пайда болады.

ChatGPT/Codex ішіндегі SharePoint байланысы жарияланған сайттың Microsoft рұқсатын алмастырмайды. Сайт үшін осы тіркеу мен әкімшінің келісімі бөлек қажет.

## Кейін басқа Microsoft тіркелгісін қосу

Бір рет бапталғаннан кейін сайт әкімшісі тіркелгіні өзі ауыстыра алады; әр ауыстыруға жаңа app registration немесе client secret қажет емес.

1. Алдымен ескі Excel файлындағы өзгерістерді сақтап, файлды жабыңыз және сайтта **Синхрондау** түймесін басыңыз. Ауыстырғанда тек дерекқорда сақталған тапсырыстар жаңа файлға көшеді; ескі файлдағы синхрондалмаған өзгерістер өздігінен көшірілмейді.
2. `/admin` бетінде Microsoft тіркелгісін ауыстыру әрекетін таңдаңыз. Microsoft терезесінде **Use another account / Басқа тіркелгіні пайдалану** арқылы қажетті жұмыс/оқу email мекенжайымен кіріңіз.
3. Жаңа тіркелгіде OneDrive белсенді болуы керек. Оның ұйымы сыртқы қолданбаларға келісімді шектесе, сол ұйымның Microsoft 365 әкімшісінің рұқсаты қажет болуы мүмкін.
4. Қосылу сәтті аяқталғанда жаңа OneDrive ішінде жаңа жеке Excel файлы жасалады. Сайтта бір уақытта бір Microsoft тіркелгісі мен бір файл ғана белсенді болады. Ескі файл бұрынғы иесінде қалады және әрі қарай синхрондалмайды; қажет болса, оны сол иесі архивтейді немесе рұқсаттарын өзгертеді.

Бұл мүмкіндік Microsoft 365 жұмыс/оқу тіркелгілеріне арналған. Gmail, Yahoo сияқты кез келген email мекенжайын немесе жеке Outlook/Hotmail тіркелгісін қосу қолдауы уәде етілмейді. Microsoft тіркелгісін қосу сайттың әкімші құпиясөзін өзгертпейді және басқа адамға әкімші бетіне кіру құқығын автоматты бермейді. Тіркелгі түрлері туралы: [Microsoft ресми нұсқаулығы](https://learn.microsoft.com/en-us/security/zero-trust/develop/identity-supported-account-types).

## Күнделікті жұмыс — телефоннан

1. Телефон браузерінен сайттың `/admin` бетіне кіріңіз.
2. **Синхрондау** түймесін басыңыз: жаңа тапсырыстар Excel-ге көшіріледі, Excel-де сақталған рұқсат етілген өзгерістер сайтқа беріледі.
3. **Excel Online ашу** сілтемесі арқылы файлды Microsoft Excel қолданбасында немесе браузерде ашыңыз.
4. Тек төмендегі төрт бағанды өзгертіңіз. Басқа бағандар тапсырыс беруші деректерін қамтиды және синхрондау кезінде өзгертілмейді.

| Баған | Не енгізу керек |
|---|---|
| Күйі | `new`, `contacted`, `confirmed`, `production`, `ready`, `shipped`, `completed`, `cancelled` |
| Әкімші ескертпесі | Клиентпен келісілген ақпарат; 5000 таңбаға дейін |
| Жеткізу құны (₸) | 0–10 000 000 аралығындағы сан; белгісіз болса бос қалдырыңыз |
| Трек-нөмір | Қазпошта берген нөмір; жіберілгеннен кейін енгізіңіз |

Күйлер: `new` — жаңа; `contacted` — хабарластық; `confirmed` — расталды; `production` — дайындалуда; `ready` — дайын; `shipped` — жіберілді; `completed` — аяқталды; `cancelled` — тоқтатылды.

5. Excel өзгерістерінің сақталғанын күтіңіз. Файлды жабыңыз. Сайтқа қайтып, **Синхрондау** түймесін қайта басыңыз.

Синхрондау автоматты түрде жүрмейді. Әр өзгерістен кейін түймені басу қажет. Қатар өңдеу қақтығыс туғызуы мүмкін: бір тапсырыстың бір өрісі сайт пен Excel-де әртүрлі өзгерсе, жүйе оны үнсіз алмастырмайды. Екі мәнді салыстырып, Excel ұяшығына сайттағы дұрыс мәнді қойып, қайта синхрондаңыз.

Клиент деректерін, жасырын ID/жаңарту уақытын және баған атауларын өзгертпеңіз; жолдарды жоймаңыз және жаңа жол/парақ қоспаңыз. Тапсырысты тоқтату үшін `cancelled` күйін таңдаңыз. Формула енгізбеңіз. Файлдың пішімдеуі және «Нұсқаулық» анықтама парағы синхрондау кезінде қайта жасалады; жеке талдау үшін оның бөлек көшірмесін пайдаланыңыз. Шегі: 5 МБ, 10 000 тапсырыс.

Егер Microsoft файл өзгергенін немесе бұғатталғанын хабарласа, Excel-дегі сақтауды аяқтап, файлды жабыңыз және қайта көріңіз. Жартылай орындалған синхрондауда кейбір өзгерістер дерекқорға сақталып үлгеруі мүмкін; жүйе келесі әрекетте оларды салыстырады, сондықтан тапсырысты қайта енгізбеңіз.

## Қазпошта арқылы қолмен жіберу

Қала, облыс, көше/үй, пәтер, пошта индексі, алушының аты мен телефоны тапсырыста сақталады. Әкімші клиентпен жеткізу құнын келіседі, жөнелтімді Қазпоштада өзі рәсімдейді, содан кейін құны мен трек-нөмірін енгізіп, күйін `shipped` деп өзгертеді. Сайт автоматты жапсырма жасамайды, Қазпоштаға брондау немесе төлем жібермейді.

## Қол жеткізу мен ақаулар

- Файлға қоғамдық немесе «сілтемесі бар кез келген адам» рұқсатын бермеңіз. Онда клиенттердің телефоны мен мекенжайы бар.
- Microsoft рұқсатын қайтарып алсаңыз немесе client secret мерзімі өтсе, техникалық маман мәндерді жаңартады, содан кейін әкімші қайта қосылады.
- `SESSION_SECRET` өзгерсе, бұрынғы Microsoft токендерін ашу мүмкін болмайды: әкімші қайта қосылуы керек.
- Қайта қосылғанда жаңа файл жасалады. Бұрынғы файлды тек қажет мәліметтерді сақтап алғаннан кейін OneDrive арқылы өзіңіз архивтеңіз.
- Қосылым дайын болмаса, `/admin` арқылы тапсырыстарды жүргізіп, Excel файлын жүктеп, өңдеп, «Өзгерістерді импорттау» арқылы кері сақтауға болады. Файл өзгерістері автоматты қайтарылмайды.

Техникалық негіз: [Microsoft OAuth authorization code + PKCE](https://learn.microsoft.com/en-us/entra/identity-platform/v2-oauth2-auth-code-flow), [Microsoft Graph файл жүктеу](https://learn.microsoft.com/en-us/graph/api/driveitem-put-content?view=graph-rest-1.0), [If-Match тексеруі бар upload session](https://learn.microsoft.com/en-us/graph/api/driveitem-createuploadsession?view=graph-rest-1.0). Синхрондауда файл нұсқасы сәйкес келмесе немесе Microsoft қақтығыс қайтарса, жүйе шартсыз қайта жүктемейді.
